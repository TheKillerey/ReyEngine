This release stabilizes experimental DynamicEffect lightmaps and replaces Map11-specific viewport visibility filters with each map's own declared layer system.

## Added

- Visibility selectors are now generated from `MapVisibilityFlagDefinitions` in the loaded map's shipping `.bin`.
- Maps can expose their own state names, bits, initial masks and additional visibility axes. Maps without declared visibility states no longer show irrelevant controls.
- Unknown state hashes remain usable and are shown explicitly when no trustworthy name can be recovered.
- Mesh layer editing, OpenGL, DX11, particles, sounds and visibility diagnostics now share the same data-driven resolver.

## Fixed

- Experimental `SRX_DynamicEffect` lightmap shaders now preserve Riot's reflected material constant-buffer bindings and carry valid rebuilt DXBC checksums.
- Live `ENV_TRANSITION` DynamicEffect permutations now receive the custom lightmapped shader, while unrelated quality and shadow variants retain Riot bytecode.
- Refreshing an already-enabled experimental shader cache is now safe and idempotent.
- Baron Pit Cup, Tunnel and Upgraded states no longer leave the Base pit geometry visible underneath them.
- Custom maps use their own `.materials.bin` controller graphs instead of being overwritten by current Riot Map11 controller objects.
- Switching projects clears cached documents for identical WAD path hashes, preventing visibility data from a previously opened map from leaking into the new project.

## Verified

- The DynamicEffect shader cache was validated through DXBC checksum, reflection binding and real D3D11 shader-creation regression checks.
- Visibility definitions were verified against installed Map11, Map12, Map21, Map22, Map30, Map33 and Map35 data.
- Controller behavior was verified against Riot `base_srx` and the custom Old Summoners Rift V2 Cursed Rift mapgeo/materials files.
- All 311 automated tests pass, the application builds successfully, and the hidden startup smoke test remains healthy.
