This release is the inspector redesign: the asset inspector is rebuilt in an Unreal/Unity-style layout with a material selector, flat property sections, an editable UV transform, always-on texture thumbnails, and a live material ball preview.

## Added

- The inspector header shows Asset, Type, Source, and Size as labeled fields, with the full asset path on hover and a copy button. The size and source were previously only available as prose inside the details text.
- A material ball preview at the top of the material detail pane: a lit sphere sampling the material's diffuse texture through its UV transform, updating live as textures or tiling change. It shows texture, tiling, and shape; the viewport's Riot Approx mode remains the reference for the actual shader.
- The UV transform (scale and offset) is edited directly in the material's General section. Values are written through the material's own UV parameters, so undo, modified state, and live preview behave exactly like a manual parameter edit; a material without a UV parameter gets one created under the canonical name, and the status line notes that the shader must read the parameter for tiling to apply in game.
- A Shaders tab holds the document-wide machinery: the shader environment selector, bulk material setup, and bulk shader replace. These act on the whole file and no longer push the per-material editor below the fold.
- Materials are selected from a dropdown above the detail pane, with search, an unresolved-only filter, and a new modified-only filter. Exactly one material is shown at a time in flat sections: General, Samplers, Render State, Derived, Switches and Macros, Parameters, Advanced.

## Improved

- Texture thumbnails are always on. The Preview toggle is gone; a selected material shows every slot's texture automatically, while unselected materials still decode nothing.
- The Overview tab shows mesh and map statistics as labeled rows instead of preformatted text blocks, and every inspector section uses the same collapsible card style.
- Opening one material from a mesh's material list now selects it in the material editor directly.
- The inspector was extracted out of the main window layout into its own compiled-bindings view, so binding errors there are build errors rather than blank panels.

## Removed

- The Raw BIN Tree tab. The material editor and the dedicated bin tooling cover its uses.

## Fixed

- The material list no longer renders all materials fully expanded; editing one of 120 materials previously meant scrolling past the other 119.
- Newly written project overrides are reported as the asset's source immediately instead of the Riot reference the asset started from.

## Verified

- All 369 automated format tests pass and the Windows startup smoke test passes. The inspector builds with compiled bindings, so every binding in the redesigned views is type-checked at build time.
