This release extends map recoloring to placed props and introduces opt-in experimental lightmap support for Riot's SRX_DynamicEffect shader.

## Added

- **Recolor Textures** now includes diffuse textures used by placed mobs and animated map props, including default skin textures and per-submesh material overrides.
- Prop textures are marked with `PROP` or `MAP+PROP` usage badges and are deduplicated when shared with map geometry.
- **DynamicEffect Lightmaps (Experimental)** appears as its own card under **Tools > Light > Bake Lighting** whenever a map is open.
- The experimental action compiles baked-light DX11 shaders for `Shaders/StaticMesh/SRX_DynamicEffect`, including its flow-ripple variant.
- Missing shader permutations are staged in a separate `ShaderCache.dx11.wad.client`. Riot's installed shader cache remains read-only.
- `NO_BAKED_LIGHTING` is cleared only for lightmapped DynamicEffect materials covered by both generated shader stages, and only after the companion cache is safely staged.

## Clarified

- DynamicEffect meshes are not excluded from lightmap UV generation. The layout generator excludes only VertexDeform foliage and render-region geometry.
- UV layout generation and DynamicEffect shader enablement are separate operations. Existing or generated UV7 data is retained while the experimental action supplies the missing client shader permutations.

## Verified

- All 33 DynamicEffect material signatures in Winter Rift 2025 resolve against the generated cache extension.
- The patch adds 32 vertex and 512 pixel permutation keys backed by three custom DXBC programs.
- DXBC reflection confirms the required UV7 input, texture slots and Riot-compatible constant-buffer offsets.
- A generated companion WAD reopens with exactly the four expected shader-cache chunks.
- All 305 automated tests pass and the Release application build completes successfully.

## Experimental warning

- DynamicEffect lightmaps modify shader-cache permutations and still require an in-game Practice Tool test. The tool creates timestamped project backups and never edits Riot's installed files.
