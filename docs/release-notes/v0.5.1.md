## Fixed

- **Got it left the menu glows on until the next start.** After an update, the menu entries whose capability changed carry a glow, and Got it in **Help ▸ What's New…** marks the release as seen. It saved that, but the glows in the open window never heard about it: they were told under a name the editor's UI framework no longer listens for, so they stayed lit until the editor was restarted. They go out the moment you press Got it now.

Nothing else changed.
