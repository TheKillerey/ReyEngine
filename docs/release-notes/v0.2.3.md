This release makes the DirectX 11 map viewport substantially more complete, turns imported Fantome archives into browsable projects, and adds a cautious project-cleanup workflow.

## Added

- **DirectX 11 now renders placed props and their idle animations.** Repeated placements share uploaded geometry, while submeshes retain their own textures and cutout state.
- **DirectX 11 editing parity improved.** The transform gizmo, visibility rules, region filtering, bucket grid, fitted light markers and live map-vertex updates now follow the main viewport.
- **Cleanup Project** previews unused and Riot-identical files before moving selected items into a recoverable project-local backup. Its reference index understands paths, hashes, converted extensions, embedded mesh names, loose hash-named chunks and project WAD contents. Uncertain results remain visibly protected.
- **Fantome imports recover custom asset names.** Unresolved WAD chunks are identified from their contents, and the mod's own `.bin` references recover real paths for custom textures and other assets that Riot's hash database cannot name.
- `run.bat` now provides `stop`, `test` and self-contained `publish` commands, and closes a running editor before replacing locked build files.

## Fixed

- **DirectX 11 now honors authored texture addressing.** Materials no longer force every ordinary sampler to Wrap; Clamp-U, Clamp-V and Clamp-UV are applied independently. This stops decals with UVs outside `[0,1]` from tiling across their entire mesh.
- DirectX 11 textures now have mip chains and anisotropic filtering, reducing distant-map aliasing without turning terrain blurry at grazing angles.
- Transparent prop fringes use alpha cutout with opaque blending and depth writes, removing bright halos and incorrect overlap.
- DirectX 11 prop and particle rebuilds release their geometry and texture resources instead of accumulating GPU objects.
- Fantome archives containing a duplicate chunk descriptor can be repaired and imported instead of losing the whole archive.
- Fantome entry paths are canonically contained, so malformed or malicious ZIP paths cannot write outside the project.
- Root-folder projects no longer copy their own `Build` directory recursively while staging a package.
- Cleanup excludes generated output, indexes packed project references, restores the latest unrestored run correctly and reports incomplete reference coverage rather than guessing.
- JPEG chunks retain a `.jpg` extension, and printable asset paths ending at the final byte are no longer missed.

## Known issues

- Map geometry still renders darker on DirectX 11 than it does in game. Prior candidate fixes were measured and reverted because they were not correct.
- Editable point lights have matching position markers on DirectX 11, but their custom illumination contribution remains available only in the OpenGL viewport and baked output.
- Fresnel and reflection cubemaps are not applied to DirectX 11 mesh-particle emitters because that mesh path does not yet carry normals.
- DirectX 11 particle vertex colours are not colour-space converted.
