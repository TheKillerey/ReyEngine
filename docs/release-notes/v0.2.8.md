This release expands map terrain rendering and fixes layered `DefaultEnv_Flat` materials so mesh-linked textures remain visible in both viewports.

## Added

- `Shaders/StaticMesh/DefaultEnv_Flat_BakedTerrain` now reads each mesh's `BAKED_DIFFUSE_TEXTURE` override and samples it with the transformed Texcoord7 atlas coordinates authored in mapgeo.
- `Shaders/StaticMesh/4TextureBlend_WorldProjected` terrain now combines its bottom, middle, top and optional extra textures through the shipping RGB blend mask.
- World-projected terrain masks use the map's actual terrain bounds and coordinate convention, keeping painted ground aligned with Map21 geometry.
- The inspector exposes mesh-owned baked diffuse and baked lightmap paths, atlas transforms and source UV channels.
- OpenGL and DX11 now support Riot's complete authored color blend-factor enum, including multiplicative and additive material passes.

## Fixed

- Ionia Base terrain no longer renders with missing, incorrectly mapped or displaced ground textures.
- Baked terrain textures no longer use ordinary material UVs when the shader expects the mesh-owned UV7 atlas.
- TFT-style layered `DefaultEnv_Flat` shadow receivers no longer cover their linked arena texture with an opaque white helper mesh.
- Synthetic legacy decals retain their established straight-alpha blending when no `StaticMaterialDef` pass exists.

## Verified

- Baked terrain and world-projected blending were checked against installed Map21 `ioniabase` and `base` assets.
- Authored blend behavior was reproduced and verified with real Map22 `aprilfool` and `7yanniversary` assets through the DX11 offscreen renderer.
- All 323 automated tests pass, the Release application builds successfully, and the hidden startup smoke test remains healthy.
