This release adds a built-in Riot asset Workshop, broadens map editing and lightmap support, and introduces direct legacy NVR/WGEO-to-mapgeo conversion with complete texture and material porting.

## Added

- The Workshop indexes installed game assets into searchable, de-duplicated material and particle galleries, with in-game thumbnails and direct insertion into the current map.
- Map Content now supports Blender-style multi-selection, batch deletion, temporary visibility, persistent object disabling, and safe prop/mob skin changes.
- Materials can replace one shader across every matching map mesh while preserving compatible textures, parameters, switches, macros, and render state.
- Legacy `room.nvr` and `room.wgeo` scenes can be ported directly into an open mapgeo project, including geometry, textures, materials, terrain blending, grass data, render regions, and rebuilt culling grids.

## Improved

- DX11 Shader Preview now restores authored shader defaults, including default textures, parameters, switches, correct texture dimensions, neutral engine textures, and PBR/IBL inputs.
- Riot extended-format BC5 normal textures are decoded for shader defaults and previews.
- The Lighting window keeps all controls reachable at smaller window sizes.
- Experimental baked-light support now covers legacy `SRX_Blend_Master` and `SRX_Blend_Chemtech_Decal` materials in addition to DynamicEffect, allowing all referenced Old Summoner's Rift atlases to bake.
- Legacy imports de-duplicate materials only when their complete runtime texture sets match, retaining the performance benefit without collapsing different surfaces onto one texture.

## Fixed

- WGEO ports now bind every imported texture through a runtime material sampler instead of relying on generic mapgeo overrides ignored by the game.
- PBR shader previews no longer render black when they depend on engine-owned shared textures or baked UVs.
- Map particle, sound, prop, and mesh visibility edits now behave consistently and survive project reloads where applicable.

## Verified

- The supplied v6.16 WGEO fixture converts to 118 optimized meshes, 118 textures, 118 distinct material bindings, and preserves all 12 destination render regions.
- The supplied NVR fixture converts 3,621 source objects into 84 meshes with 81 unique material sets.
- Real Map11 material, lightmap, mapgeo, NVR, and WGEO fixtures round-trip successfully; all 351 automated format tests and the Windows startup smoke test pass.
