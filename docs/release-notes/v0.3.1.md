This release makes the Direct3D 11 viewport a real second renderer rather than a preview, teaches the editor a map bin's actual schema, and fixes four defects that could make a shipped map mod crash or render nothing in game.

## Added

- **Direct3D 11 viewport parity.** The skybox (all three sources), soft particles with real depth, and beam/trail ribbon emitters now render in D3D11, alongside paint strokes and the paint brush ring. The viewport clears to the same background as the OpenGL one, and honours each material's authored back-face culling.
- **Map bin schema awareness.** ReyEngine adopts LeagueToolkit's meta-class database, so the Map Bin Editor and the Material Editor can show the fields an object does *not* set, along with their authored defaults — and add a missing field at that default rather than inventing a value.
- **Schema-aware bin validation**, which catches problems that "does it parse" cannot.
- **Image import as .tex.** A conversion dialog with format, mipmap and compression settings and a live output-size preview, sized from a survey of what Riot actually ships. Replacing an existing texture converts too, so a PNG can be dropped straight onto a `.tex` slot.
- **Environment state transitions.** Map-state data (grass tint, alternate assets, transition times) is parsed from the map bin, the grass tint resolves from `mGrassTintTexture` and follows the active map state, and the crossfade between states runs in both viewports with Riot's own transition VFX firing on the change.
- **Bucket-grid bake controls.** The bake's height range and target bucket size are editable, with a violet preview volume drawn in both viewports showing exactly what the next rebuild will cover, and a live read-out of grid/cell counts.
- **Bin editor usability**: real field names and resolved link targets, texture previews, colour swatches, and the ability to add fields (including `Color`).

## Improved

- The translate gizmo has a cone arrowhead in both viewports, and the D3D11 selection outline is now the same wireframe the OpenGL viewport draws instead of a translucent fill.
- Hidden placeables are no longer clickable — one gate per category, so hiding particles, sounds or mobs also removes them from picking.
- A per-click picking trace can be switched on from the toolbar when a selection looks wrong.
- Riot's encrypted esports banner textures are named as such instead of being reported as broken.

## Fixed

- **A map mod could crash the game at load** from a materials.bin whose nullable structs were written in the long form. Every byte after the first one was misread. ReyEngine now repairs that on load instead of silently dropping the affected objects — which previously lost every placement in them, permanently, on the next save.
- **An empty container in a bin also crashed the game at load.** Riot ships none in 33,645 materials; ReyEngine no longer writes one.
- **Ported terrain rendered nothing in game.** Material containers must hold `Embedded` elements; the porter wrote the pointer form. Both parse and round-trip identically, so nothing in the toolchain noticed — the map simply drew nothing. This affected every ported map.
- **Blend passes wrote only half the blend equation.** The colour and alpha factors move in pairs; writing `dstColorBlendFactor` without `dstAlphaBlendFactor` left premultiplied surfaces fully transparent.
- **Deleting or moving particles and sounds did nothing to the exported mod.** The edits were saved to the workspace override store, which the packager discards when a project folder already provides that asset — so the save succeeded and the export was unchanged. Placement, mapgeo and audio-bank saves now write the project file. Mesh moves and deleted meshes were being dropped the same way.
- Applying a shader look-preset no longer strips a geometry fact the material declares.
- Emissive parameter names are normalised like every other lookup, so authored emissive values are found.
- OpenGL no longer invents a sun term on `NO_BAKED_LIGHTING` surfaces, and its emissive glow is ported from Riot's shader rather than approximated.
- The grass tint is applied correctly in both renderers: the OpenGL path was missing Riot's V flip, the D3D11 path never received the texture path, and the state lookup compared a mask against a bit index.
- The camera no longer drifts or locks during an environment transition.
- Fixed a latent undefined-behaviour case in a shadow comparison sample, and corrected an earlier note that claimed a shader-specific darkening existed — it does not.
- The Map Bin Editor window failed to open in some cases.

## Verified

- 589 automated format tests pass, and the solution builds clean.
- The four map-mod defects above were each confirmed against a real mod: the map now loads and its ported terrain renders in game, having previously crashed at load and then drawn nothing.
