Particle rendering catches up on the DirectX 11 viewport, and lighting work is no longer lost when a map reloads.

## Added

- **Heat haze renders on DirectX 11.** Distortion emitters previously drew their placeholder sprite, which is a deliberately blank white texture, so they appeared as solid white cards over the map. They now refract the scene behind them, as they always have on OpenGL.
- **Mesh particle emitters render on DirectX 11.** Emitters that draw a real mesh rather than a billboard — the Jade base door shields, for example — were counted as skipped and never drawn. They now render, textured, transformed and animated, in both the map viewport and the particle preview window.
- **Lighting is saved with the project.** Sun and sky colour and intensity, the baked-light scale, the Light.dat fit sliders and the point-light table itself are stored per map and restored when the map is reopened. Previously every map load reset them, and lights added by hand were lost when the editor closed.
- **The light table is a real list.** The Lighting window now shows the lights it was reporting a count for, with multi-selection, so several can be removed at once. Added **Delete selected** and **Remove all**. Previously lights could only be reached one at a time through the outliner, which does not scale to an imported Light.dat of several hundred.
- **Lightmaps can be recoloured.** Baked lightmap atlases now appear in the Texture Recolor tool alongside diffuse textures, so a map's baked light can be tinted with the same hue, saturation and levels controls. Lightmap rows are marked and count the mesh groups that use them.

## Fixed

- **Point lights were far too bright after a map reload.** Restored lights had their colour scaled twice, saturating every one. This surfaced after baking, because baking is what reloads the map.
- A texture bound for one purpose could be handed to a differently-named sampler that shares a prefix, so an emitter authoring both a diffuse and a multiply texture could read the wrong one.

## Known issues

- Map geometry still renders darker than the game does. Two candidate fixes were tried during this cycle, measured, found wrong and reverted, so neither ships here. The cause is not a missing light, a missing shader constant or the map's fog — all three were ruled out by measurement. Investigation continues.
- Fresnel and reflection cubemaps are not applied to mesh particle emitters on DirectX 11. They need per-vertex normals that the mesh path does not currently carry.
- Particle vertex colours are not colour-space converted on DirectX 11.
