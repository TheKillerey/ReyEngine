A small follow-up to v0.1.8: classic maps now look the same whether you open them on their own or stand a champion in front of them — plus a new logo and a Tools menu you can actually navigate.

## 🌄 Map backdrops match the standalone map viewer (M142.9)
- v0.1.8 rendered Twisted Treeline's ground correctly in **Open Legacy Map**, but previewing a champion *against* it fell back to the old flat-tile ground — the backdrop draws through a different renderer that never received any of the v0.1.8 map work.
- The backdrop now gets the same treatment: the **height-blended ground** with its baked composite atlas, the **night lighting** baked into each mesh's vertex colours, and the per-submesh **alpha and decal handling**. Set Twisted Treeline as your backdrop and it matches the standalone viewer.
- Crystal Scar's look is deliberately untouched — it has no baked composite ground, so it keeps its established shading. It does pick up the alpha fixes, so its foliage stops rendering as opaque quads.
- Tuning note: for composite-ground maps the **Bright** slider is the knob (its default is exact parity with the standalone viewer); **Ground** no longer applies, since the baked vertex lighting replaces the term it drove.

## 🎨 New logo & a sorted Tools menu (M143)
- A wide **ReyEngine wordmark logo** with a transparent background, built from the existing emblem — it reads correctly on both GitHub's light and dark themes.
- The **Tools menu** was 16 entries in one flat list (with Build Package duplicated from Project). It's now grouped: the three *Open in … Editor* actions first, then the Assign actions, then **Mod Health**, **Hashes & Names** and **Shaders** submenus. Every tool is still there — just findable.

## 🔧 Under the hood
- Release changelogs now live in the repo (`docs/release-notes/<tag>.md`) and ship with the build, so a release can't go out with empty notes again — as v0.1.8 briefly did.

**Install**: download the zip, extract anywhere, run `ReyEngine.App.exe`. Settings and projects carry over.
