**Paint straight onto a League map with a brush**, plus a whole-map texture recolour tool with `.cube` colour grades — and a fix for a `.tex` writer bug that was destroying cutout transparency.

## 🖌️ Paint on meshes (M172)

Toggle **🖌 Paint** in the viewport toolbar, pick a colour and a size, and left-drag on the map. Strokes appear instantly — no reload — and **Save painted textures** writes them back as real `.tex` files.

This works because of something measured rather than assumed: on Summoner's Rift **UV0 never tiles** (global extremes u[-0.0235, 1.0169]), 159 of `base_srx`'s 169 diffuse textures belong to exactly one submesh, and **92.3% of texels map to exactly one world location**. Painting into a shared diffuse texture is normally hopeless — a dab lands wherever those UVs appear — and on SR it simply isn't.

- **World-unit brush size.** Texel density across the map varies by orders of magnitude, so a texel-sized brush would be a speck on the ground and swallow a prop whole.
- **A brush ring** lying on the surface, showing the true footprint — it foreshortens on slopes and grows as you zoom, because the brush really is a world-space sphere.
- **Brush tips**: Soft, Hard, Square, Speckle, Grain, Chalk, Spatter, Ring — plus **import any PNG/TGA/DDS/`.tex`** as your own stencil.
- **Blend modes**: Normal, Multiply, Screen, Overlay, SoftLight, Add, Subtract, Darken, Lighten, Color, Luminosity. *Color* recolours a surface without flattening the detail painted into it.
- **Seam bleed**, so a stroke crossing a UV island edge doesn't leave a hairline crack that filtering and mipmaps then widen. 51 of 159 textures have more than 64 islands — this is not an edge case.
- **Per-stroke undo**, stored as 64×64 texel tiles rather than whole 16 MiB textures.

Three things it deliberately never does: write alpha (609 of Map11's BC1 textures carry cutout data there), paint texels the texture cuts away, or paint through backfaces.

**Warnings where they matter.** Hovering names the texture and says how many meshes share it — painting one bush repaints all 73. `Periph_Vista` is blocked outright: it's 33.7% of the map's world area with its texture stacked 5.04× over, so one dab would appear five times across the horizon.

## 🎨 Recolor Textures (M171)

**Tools ▸ Recolor Textures…** — hue, saturation, brightness, contrast, levels, gamma, per-channel tint and an overall strength, applied across as many of the map's textures as you pick. Six presets to start from.

- **Adobe/IRIDAS `.cube` colour grades**, 1D and 3D, trilinear, with their own strength slider.
- **Non-destructive.** The project stores the *sliders*, not the recoloured pixels; every apply re-derives from Riot's original. Over ten successive hue nudges that's **47.1 dB against 33.4 dB** for chaining edits — the difference between a texture you can keep tuning and one that visibly rots.
- **Restore originals** undoes a run.

## 🐛 The `.tex` writer was destroying cutout alpha

Our BC1 encoder never looked at alpha, and force-ordered the endpoints before the punch-through check — so the branch meant to enable BC1's transparent mode could never run. On Map11 that's **609 of 6,862 BC1 textures** carrying cutout alpha, median 38.8% of their texels transparent. Round-tripping eleven of them kept **0.0%** of those texels; every cutout would have filled in solid.

Encoding now goes through BCnEncoder: alpha RMSE **0.000**, 100% of transparent texels intact, and round-trip colour error drops from ~2.07 to ~0.43 (13.9 dB). Source pixel format is preserved too — 160 of `base_srx`'s 169 diffuse textures are BC1, and silently promoting them to BC3 would have roughly doubled each one.

## ⚡ Faster picking

Click-selection ran a brute-force test over all 909,993 map triangles at **11.13 ms per ray**, twice per click. A BVH replaces it at **1.28 µs** — and returns the UV under the cursor, which is what made painting possible. Over 3,000 rays both agree on the submesh every time, with bit-identical distances.

Also fixed: every texture refresh (material edit, recolour, re-bake) was leaking the entire previous texture set — about **2.2 GB of VRAM** each time.

## 🔍 A correction

Earlier versions claimed in the Overlay Footprint tool that a wide WAD overlay ("200+ WADs") had crashed the game. That was a false diagnosis. The real cause is a `MapCubemapProbe` pointing at a plain 2D texture instead of a DDS cubemap — the engine binds one image where it needs six faces. **Tools ▸ Mod Health ▸ Check Cubemap Probes** finds it. A wide overlay costs install time and merge complexity, but it does not crash anything.

**Install**: download the zip, extract anywhere, run `ReyEngine.App.exe`. Settings and projects carry over.

**Note on painting**: strokes edit the shared `.tex`, so every Map11 map skin using that texture changes — the hover badge names the count. Nothing is written until you press Save, and Restore originals reverses it.

**Known gap**: 165 of 184 `base_srx` materials carry a `TintColor`, and 140 share one neutral value — so paint should land literally across the bulk of the map. The shader's exact blend formula is still unmeasured, so check a test texture in game before committing to a large repaint.
