This release opens the editor up to outside tools — a live link to Blender, mod packages that install straight into LTK Manager, and projects that carry themselves across a Riot patch on their own. It also turns the legacy map porter from a geometry converter into something that brings a whole old map across: its particles, its sounds, its lights and its decals. Along the way it closes a defect that made every ported decal render black in game, and several that stopped a mod loading at all.

## Added

- **Live Blender link.** Pull a map's geometry into Blender, edit it there, and push the changed shapes straight back into the mapgeo. The link tracks what actually changed rather than re-sending the map, so a push applies in seconds instead of freezing on a map-sized transfer.
- **Face editing in the viewport.** Select faces, move them with the gizmo, and extrude or inset them. Edits are visible while you make them and survive the save.
- **Legacy particle porting.** A legacy map's own `.troybin` particles convert into the Workshop with their curves, force fields, spawn volumes, emitter rotations, flipbook rates and probability tables — the randomisation that makes an effect read as three-dimensional rather than flat — with a live preview while you tune them.
- **Legacy map audio.** The source client's map sounds port into a bank current League can actually load, extending the map's own banks rather than shipping a replacement.
- **Navgrid support**, with a bush overlay drawn in the viewport. Every navgrid flag is its own layer, so the gameplay bush is visible as the game sees it rather than inferred from geometry.
- **A lighting suite.** Bake and link a lightgrid without needing a lightmap layout, save the map's sun and sky (a writer that never existed before), port a legacy map's point lights onto real dynamic placements, set a map-wide lighting mode, adjust light strength and height in bulk, and clean lightmaps back to their pre-bake state.
- **Ritobin text editing.** Open a `.bin` as ritobin text — the format the modding community edits bins in — change it, and write it back byte-exactly.
- **Material browser and bulk material work.** Audit every material in a map against the meshes that use it, then copy one material's look onto twenty after seeing exactly what will change. Sampler address modes and shader macros are editable, and the macro panel says what the shader will actually do with each define.
- **Automatic Riot patch rebasing.** A project can carry its edits forward onto a new patch by three-way merge instead of being re-made by hand.
- **Send to LTK Manager.** Create or update a workshop mod in place, writing source files to the folder the manager watches rather than touching its library.
- **Second UV set viewer and editor**, and the ability to add `Texcoord7` to a selected mesh without an atlas or a bake — the channel previously had no way to be seen or changed.
- **Game Mode** — one switch for "show me what the game shows".
- **Map graphics features**, filled from a map Riot ships with them, with a guard for the five features Riot never ships.
- **Mesh import from another map**, and changing the material on a mesh already placed in one.
- **New features point themselves out.** After an update, the menu entries and viewport toggles that
  are new in this release carry a subtle glow until you have looked at them. It is version-aware
  rather than tied to this release, so the same mechanism serves the next one.
- Native Mimir `.hashdb` reading, so hash tables no longer ship as 554 MB of text.

## Improved

- The viewport toolbar is three menus instead of 28 buttons, the inspector is sectioned into Object / Map / Asset tabs, and the content browser and console share one dock.
- The window wears its own chrome, and the secondary windows' caption buttons work.
- The legacy port remembers what it was last run with, so re-running it to change one option no longer means re-deriving the other twelve from memory.
- A legacy import's position can be fine-tuned without re-porting, and the alignment correction is a measured value you can edit rather than a constant only a rebuild could change.
- Ported materials and textures lose the content-hash suffix from their names.
- Every library moved to its latest release.
- The shader catalogue cache expires, so a client update is picked up.
- Particle playback matches the authored data: a flipbook with no authored frame rate holds its cell instead of inventing one, and a slow, long-lived emitter warms up to the density the game shows rather than appearing empty.

## Fixed

- **Ported decals rendered black in game.** The cause was a blend factor that reads the framebuffer's alpha, compounded by a depth rule the editor was more forgiving about than the client. Decals now draw last, and the editor applies the game's depth rules rather than a kinder version of them.
- **A single 1×1 texture could stop a whole map loading.** Block-compressed textures must sit on the 4×4 block grid; one 1×1 file kept the map from loading with no indication which file was at fault.
- **Texture paths disappeared on patch 16.17**, which changed them from strings to 64-bit chunk links. A reader that only understood strings returned nothing, and a patch rebase alone left a mod on the old form.
- **A material with an unnameable texture rendered white**, and a ported map's own textures could not be named at all.
- **An imported mesh was invisible in game** — it carried no second UV set, so the client skipped the draw.
- **Baking a lightgrid dimmed every character on the map** to a quarter of their intended brightness, from a hardcoded value no shipped map uses.
- **Ported decals were cut at the wrong alpha**, from a corpus measurement taken over the wrong population, and were left wrapping when they should clamp.
- **A save could rewind the rest of the file**, discarding edits made elsewhere in it.
- **Face edits never reached the save at all**, and a moved face still picked in its old position.
- **Auto-save could never be turned on.**
- **Material edits reached the OpenGL viewport and nothing else.**
- **The D3D11 viewport drew a cropped picture and picked against the full one.**
- **A container written with the wrong wire tag made the client read a different material** — the file parsed, round-tripped and diffed identically, and the game silently used the shader's defaults.
- **Two crashes on load**: a mapgeo parse desync, and a list written in the wrong form.
- **Deleting a mesh was the one map edit you could not undo.**
- **The map's sun was applied on open and overwritten a line later.**
- Four-blend terrain sampled its blend mask with tiling diffuse UVs, always carries `Texcoord7`, and the ported vertex layout used an element order Riot never ships.
- Legacy particles were flat: the primitive was wrong, the flipbook needed the atlas grid rather than a frame count, and ~1,900 values were scaled by the wrong factor.
- The material picker reverted every selection and offered the wrong set.
- The back-face culling toggle never reached D3D11, and the operator said the opposite of what it meant.
- An uncapped frame loop, and hash tables that were not built for the threads reading them.
- A packed mod no longer ships the same bytes twice — 686 MB down to 406 MB on a real mod.

## Verified

- 1,657 automated tests pass and the solution builds clean.
- The map-mod defects above were each confirmed against real mods in game, not only in the editor — including the black decals, the load-blocking texture, the invisible mesh and the decal alpha cut.
