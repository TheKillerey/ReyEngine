A small release about the previous one: v0.4.8's work never reached What's New.

## Fixed

- **What's New skipped a whole release.** The list is built from features that each highlight a menu entry, so a release that adds no new entry point had nothing it could list - and the window left the release out altogether, heading and all. v0.4.8 made maps with particles, animated props and lights draw far faster and fixed two things about capturing a sequence, and the window had nothing to say about any of it. A release can now carry lines of its own without a menu entry behind them: they are listed and marked NEW like anything else, and nothing in the menus glows for them, because there is nothing to point at. v0.4.8's two lines are there now, and Got it acknowledges the release you are actually running.
