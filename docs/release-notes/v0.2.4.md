This release adds a live-tested map-skin workflow and reduces the frame overhead of very large map projects in both viewport backends.

## Added

- **Map Skin Switcher** creates complete normal-map skin overrides from environments already shipped by Riot. For example, Map11 Default / Base_SRX can load Milkshake_SRS visuals, music and ambience without renaming map files.
- The switcher preserves every registered slot and internal alias's runtime identity while routing its container, object configuration, world particles and grass tint.
- A generated compatibility materials bin keeps the current/base map's server-facing gameplay IDs while retaining the selected environment's authored objects and skins. This prevents the `StartSpawn` null lookup that made route-only packages crash.
- Dedicated source Wwise banks, background music and ambience are routed through the active base feature identity.
- Both generated bins, dependency graphs and asset references are validated before saving. Timestamped backups and a detailed compatibility report are written into the project.
- Map22 and TFT arenas remain deliberately unavailable because they are paid cosmetics.

## Improved

- **Large OpenGL maps submit less off-screen work.** Conservative per-slice and per-prop frustum culling, cached opaque draw order and redundant texture-bind elimination reduce CPU and driver overhead while retaining GPU rendering.
- **DirectX 11 presentation and editor overlays do less host-side work.** Marker, highlight and visibility inputs are cached, marker buffers are reused, and tightly packed frames reach Avalonia with one copy.
- The displayed DirectX 11 frame time now includes both rendering and presentation.
- Reapplying the same map-skin selection is safe and does not stack edits or omit its audio references from validation.

## Verified

- Base_SRX to Milkshake_SRS was tested in game through match startup and play; the map and Winter background music both load.
- Riot's current Map11 data routes 36 MapSkin definitions and aliases, 97 environment fields, 2 audio fields and 2 server placeable identities.
- The rebuilt 589-chunk Winter Rift WAD reopens successfully and contains the expected server keys and Milkshake music event.
- All 292 format tests pass, the application builds successfully, and a minimized Windows startup smoke test remains running.

## Known issues

- Map geometry still renders darker on DirectX 11 than it does in game. Prior candidate fixes were measured and reverted because they were not correct.
- Editable point lights have matching position markers on DirectX 11, but their custom illumination contribution remains available only in the OpenGL viewport and baked output.
- Fresnel and reflection cubemaps are not applied to DirectX 11 mesh-particle emitters because that mesh path does not yet carry normals.
- DirectX 11 particle vertex colours are not colour-space converted.
