A small release of small things, and one bug that was not small: the highlights that were supposed to point out new features after an update had never shown, in any release since they were added.

## Added

- **Help ▸ What's New…** lists every feature by release, newest first, with the ones this install has not acknowledged marked — and its **Got it** is the one place that puts the menu highlights out. The command to do that has existed since v0.4.0; nothing called it.
- **Animated GIF backdrops.** A `.gif` behind the editor plays now, in every window, decoded once and shared; a still GIF stays a still.
- The **Mobs and animated props** switch under Overlays highlights for the prop work of v0.4.4, so the release's third change has a control that says so.

## Fixed

- **New-feature highlights never appeared.** The registry behind them was initialised from a list declared further down the same file, and C# runs static initialisers in order — so it was empty in every real run, every highlight threw, and the throw was swallowed as a binding error. The test suite never noticed because each test class resets the registry first; a headless run of the new What's New window, a fresh process with nothing reset, is what caught it.
- Every text box's placeholder used a property Avalonia has retired; fifty of them, now on the current one. No visible change, and a clean build log.
