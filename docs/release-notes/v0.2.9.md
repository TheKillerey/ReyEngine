This release makes missing League references and lightmap bake coverage explicit, so failed recolors and empty bakes no longer look successful.

## Improved

- Project Settings now validates and normalizes the selected League `Game` folder and gives users direct recovery steps when required reference archives are unavailable.
- Texture recoloring reports missing original textures separately, marks partial runs as errors and records only textures that were actually written.
- Long console diagnostics wrap inside the import log instead of being clipped at the panel edge.
- Current Riot Live installations are recognized without the retired `Common.wad.client`; older installations still mount that archive when it exists.

## Fixed

- Lightmap baking now counts only atlas pages containing material-eligible meshes instead of promising pages that cannot be baked.
- A zero-coverage bake is stopped with an actionable DynamicEffect shader instruction rather than finishing with zero output textures.
- Enabling experimental DynamicEffect lightmaps refreshes the material profiles immediately, so the bake filter sees the patched shader state without reopening the map.
- Generated lightmap atlases are written into the map's shipping WAD and stale override copies are repaired only after the durable output succeeds.
- Zero shadow, point-light and ambient-occlusion sample settings still bake the unshadowed sun, sky and point-light colors.

## Verified

- League folder normalization, current Live WAD layout, map-WAD discovery and missing recolor sources are covered by automated regression tests.
- Lightmap coverage, zero-sample lighting and atlas output behavior are covered by automated regression tests.
