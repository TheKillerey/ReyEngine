A small release out of one bug report. A user swapped a map skin and got default turrets on both sides, then tried editing the map's bin by hand and got a map that loaded with no textures at all. Neither was corruption — both were things the editor knew and did not say — so this release makes it say them, and closes a category of silent mistake while it is there.

## Added

- **The Map Skin Switcher shows what a map skin does to units.** A map skin can force the skins of the turrets, minions and nexus, and 13 of Summoner's Rift's 37 slots do. The switcher now names them per slot, so it is visible at a glance that Hall of Legends forces none at all — which is why switching to it could never bring its turrets along.
- **An option to carry those unit skins with the swap.** Off by default: the four fields the switcher has always routed describe a *place*, while these describe units the server spawns. The result reports how many slots had theirs replaced and how many were given one, because a slot that shipped without the field is a case Riot's own data has no example of — check it in game before shipping a mod with it.
- **The ritobin editor warns when a save would change a property's type.** Every property in a `.bin` carries a one-byte type tag and the client dispatches on it; give a field the wrong tag and the client does not complain, it *skips* the property — the file loads and the field is simply gone. The check compares against the bin that was opened rather than a schema, so it catches forms this build has never heard of, and it stays quiet for ordinary value edits.
- **The particle editor explains the rows it used to refuse.** A struct with no fields of its own read as "unsupported type or Riot reference" — a message about type support in front of a row whose *class* is its entire content. `primitive` is the one that matters: it decides whether an emitter is a billboard, a mesh, a ray or a trail, and it now says which, plus a warning when the preview cannot draw that shape and falls back to a billboard.

## Improved

- Asset links in particle bins are editable. Patch 16.17 turned those references into a link type that the editor's row list had never been told about, so they sat read-only for no reason of their own.
- A matrix row says why it is read-only — it is shown rounded for readability, and editing that text back would quietly round the matrix on every save — instead of claiming its type is unsupported.
- Struct rows name their class. Riot's structs are polymorphic, and a header reading "(3 fields)" never said which of eleven classes was in front of you.

## Fixed

- Nothing was corrupting these files. The live Summoner's Rift shipping bin goes through every one of the editor's write paths — material editor, ritobin text editor, map skin switcher — and comes back with its type tags intact. The reported symptoms were a field the switcher does not route by design, and a hand edit that re-typed texture paths from a link to plain text.
